# v0.1 plan

The goal is a playable local prototype. Two players form factions, contest a territory, fight in the same arena, and see the result on the shared map.

## Steps

1. **Scaffold the app.** Set up the TypeScript workspaces, React/Vite client, and Colyseus server with one command to start local development. Add Express routes in the same service as HTTP endpoints become necessary.
2. **Build a small world map.** Use three fixed territories, guest players, and basic faction creation. Keep world state in memory and use one Colyseus room to handle lobby actions and broadcast gathering windows and ownership changes.
3. **Connect the battle flow.** Enforce attack eligibility on the server. Each attacking faction gathers for 30 seconds from its own declaration, then can enter the territory's shared Phaser arena in a Colyseus room. Allow factions to declare during active fights and players to join their faction mid-fight. The current owner can enter without gathering.
4. **Make the arena playable.** Start with one fixed arena layout, placeholder pixel art, movement, aiming, and shooting. Add one central capture point. The server resolves captures and applies ownership changes without ending the arena fight. Neutral territories use the same capture point.
5. **Verify the full loop.** Use two independent browser sessions to check independent gathering windows, entry into the same arena, respawning, and ownership updates on both world maps. Test movement and hit registration under simulated latency before deciding whether to add client-side prediction or lag compensation.

## Prototype arena rules

- A faction without holdings can attack any territory. A faction with holdings can attack any territory that shares a land border with one or more of them.
- Defenders spawn near the center. Each attacking faction spawns around its own virtual point at the edge of the map. Leave the number of attacking factions uncapped in this version.
- Players have unlimited lives and ammo. They respawn at their faction's spawn location after a short delay. Try five seconds initially.
- Every player starts with one equipment slot for a weapon, occupied by an AK-47.
- Territory fights have no overall time limit, reinforcement tickets, resource costs, or cooldown between attacks. The respawn delay applies to the individual player.
