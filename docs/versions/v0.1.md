# v0.1 plan

The goal is a playable local prototype. Two players form factions, contest a territory, fight in the same arena, and see the result on the shared map.

## Steps

1. **Scaffold the app.** Set up the TypeScript workspaces, React/Vite client, and Colyseus server with one command to start local development. Add Express routes in the same service as HTTP endpoints become necessary.
2. **Build a small world map.** Use three fixed territories, guest players, and basic faction creation. Keep world state in memory and use one Colyseus room to handle lobby actions and broadcast gathering windows and ownership changes.
3. **Connect the battle flow.** Let one faction challenge a territory and a second faction contest it during a short gathering window. When the window closes, send both players into the same Phaser arena backed by a dedicated Colyseus room for that battle.
4. **Make the battle playable.** Start with one fixed arena, placeholder pixel art, movement, aiming, and shooting. Try first to three eliminations as the provisional win rule. The server decides the winner and applies the territory ownership change.
5. **Verify the full loop.** Start the app locally and play through the flow in two independent browser sessions. Both players should see the same battle result and the same new owner on the shared map. Test movement and hit registration under simulated latency before deciding whether to add client-side prediction or lag compensation.

## After v0.1

Add PostgreSQL persistence, the 6 × 6 flag editor, procedural arenas, and daily ownership snapshots with a history book.
