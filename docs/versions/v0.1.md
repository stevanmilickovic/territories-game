# v0.1 plan

The goal is a playable local prototype. Two players form factions, contest a territory, fight in the same arena, and see the result on the shared map.

## Steps

1. **Scaffold the app.** Set up the TypeScript workspaces, React/Vite client, and Express/Colyseus server with one command to start local development.
2. **Build a small world map.** Use three fixed territories, guest players, and basic faction creation. Keep world state in memory for this version.
3. **Connect the battle flow.** Let one faction challenge a territory and a second faction contest it during a short gathering window. Send both players into the same Phaser arena when the window closes.
4. **Make the battle playable.** Start with one fixed arena, placeholder pixel art, movement, aiming, and shooting. Try first to three eliminations as the provisional win rule. The server decides the winner and applies the territory ownership change.
5. **Verify the full loop.** Start the app locally and play through the flow in two independent browser sessions. Both players should see the same battle result and the same new owner on the shared map.

## After v0.1

Add PostgreSQL persistence, the 6 × 6 flag editor, procedural arenas, and daily ownership snapshots with a history book.
